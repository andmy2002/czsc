# 个人财务记账系统 - 产品需求文档

## 1. 项目概述

### 1.1 项目名称
个人财务记账系统 (Personal Finance Tracker)

### 1.2 项目类型
单页面Web应用 (SPA)

### 1.3 核心功能
帮助个人用户管理多个账户、记录日常收支流水、进行统计分析的个人财务管理工具

### 1.4 目标用户
- 需要管理日常收支的个人用户
- 小型家庭财务管理者
- 希望追踪消费习惯的用户

### 1.5 核心价值
- 简单易用：无需培训即可上手
- 数据安全：本地存储，隐私保护
- 功能完整：覆盖账户、流水、统计三大核心功能

---

## 2. 功能需求

### 2.1 多账户管理

#### 账户属性
- 账户名称（如：现金、微信、支付宝、银行卡、花呗等）
- 账户类型（现金、银行卡、电子钱包、信用卡等）
- 账户颜色（用于界面区分）
- 当前余额（自动计算）
- 账户创建时间
- 账户备注说明

#### 账户操作
- 创建账户：添加新账户，设置名称、类型、颜色、初始余额
- 编辑账户：修改账户信息
- 删除账户：删除账户及其所有关联流水
- 查看账户详情：查看该账户的所有流水记录和余额变化

### 2.2 收支流水记录

#### 流水属性
- 日期：记录日期（必填）
- 账户：从已有账户中选择（必填）
- 类型：收入/支出（必填）
- 金额：正数，精确到分（必填）
- 分类：餐饮、交通、购物、工资、红包、转账、居住、医疗、教育、娱乐、其他（必填）
- 备注说明：可选的补充说明
- 创建时间：系统自动生成

#### 流水操作
- 新增流水：记录一笔收入或支出
- 修改流水：编辑已有流水
- 删除流水：删除指定流水
- 查看流水列表：按时间倒序显示所有流水

### 2.3 统计与查询功能

#### 时间维度统计
- 按日统计：当天总收入、总支出、净结余
- 按月统计：当月总收入、总支出、净结余
- 按年统计：当年总收入、总支出、净结余

#### 分类维度统计
- 按支出分类统计各分类金额和占比
- 按收入分类统计各分类金额和占比
- 支持饼图/柱状图可视化展示

#### 账户维度统计
- 各账户当前余额
- 账户余额变化趋势

#### 筛选功能
- 时间范围筛选：自定义起始日期和结束日期
- 账户筛选：选择单个或多个账户
- 类型筛选：仅收入/仅支出/全部
- 分类筛选：选择具体分类

## 3. 技术方案

### 3.1 技术栈
- **前端框架**：原生 HTML5 + CSS3 + JavaScript (ES6+)
- **数据存储**：LocalStorage（浏览器本地存储）
- **图表库**：Chart.js（用于数据可视化）
- **图标库**：Font Awesome 6
- **字体**：Google Fonts（Noto Sans SC 思源黑体）

### 3.2 数据结构

#### 账户数据
```javascript
{
  id: "uuid",
  name: "账户名称",
  type: "cash|bank|ewallet|credit",
  color: "#HEXCOLOR",
  initialBalance: 0,
  createdAt: "ISO日期时间"
}
```

#### 流水数据
```javascript
{
  id: "uuid",
  date: "YYYY-MM-DD",
  accountId: "账户ID",
  type: "income|expense",
  amount: 金额,
  category: "分类名称",
  note: "备注说明",
  createdAt: "ISO日期时间"
}
```

#### 分类配置
- 支出分类：餐饮、交通、购物、居住、医疗、教育、娱乐、通讯、理财、其他
- 收入分类：工资、奖金、理财、红包、转账、退款、其他

### 3.3 页面结构
- 顶部导航栏：Logo、页面切换标签
- 侧边栏：账户列表、快速统计
- 主内容区：各功能页面
- 底部：版权信息和数据导入导出

## 4. 界面设计

### 4.1 设计风格
- 现代简约风格
- 浅色主题为主
- 卡片式布局
- 柔和圆角和阴影

### 4.2 配色方案
- 主色：#4F46E5（靛蓝色）
- 收入色：#10B981（绿色）
- 支出色：#EF4444（红色）
- 背景色：#F9FAFB（浅灰）
- 卡片色：#FFFFFF（白色）
- 文字色：#111827（深灰）

### 4.3 字体
- 主字体：Noto Sans SC（思源黑体）
- 数字字体：DM Sans（清晰的数字显示）

## 5. 验收标准

### 5.1 功能验收
- [ ] 可以成功创建、编辑、删除账户
- [ ] 可以成功添加、修改、删除收支流水
- [ ] 统计数据准确反映实际情况
- [ ] 筛选功能正常工作
- [ ] 数据刷新页面后不丢失

### 5.2 性能验收
- [ ] 页面首次加载时间 < 2秒
- [ ] 操作响应时间 < 200ms
- [ ] 支持至少1000条流水记录

### 5.3 兼容性验收
- [ ] 支持 Chrome、Firefox、Safari、Edge 浏览器
- [ ] 支持手机端响应式布局

---

## 6. 可扩展改进建议

1. **数据导入导出**：支持 Excel/CSV 格式导入导出
2. **数据备份**：支持云端备份（需后端服务）
3. **多币种支持**：支持外币账户
4. **预算管理**：设置月度预算，支出提醒
5. **数据报表**：生成月度/年度财务报表
6. **数据加密**：敏感数据加密存储
7. **多语言支持**：支持中英文切换
